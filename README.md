🎮 Simon Says Game

A fun memory-based game where players repeat a sequence of colors and sounds in the correct order.

✨ Features

- Interactive color buttons.
- Random sequence generation.
- Increasing difficulty levels.
- Score tracking.
- Game-over functionality.

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

🎯 Objective

To improve memory and concentration by remembering and repeating increasingly longer sequences.

👨‍💻 About

A beginner-friendly JavaScript project developed to practice DOM manipulation, event handling, and game logic.
